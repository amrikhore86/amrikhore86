## Projects

### [EASM: External Attack Surface Mapping](https://github.com/amrikhore86/easmap)
A Python tool for mapping an organization's externally visible web attack surface.
- Passive reconnaissance using publicly accessible website resources
- Optional active checks, run only against explicitly specified targets
- Deterministic, rule-based assessment logic (no AI model involved)
- Generates readable PDF assessment reports

`Python` `Reconnaissance` `Automation`

### [API Security Quest](https://github.com/amrikhore86/apisec-quest)
A story-driven, hands-on environment for learning the OWASP API Security Top 10. It is in development, with a Svelte frontend and a FastAPI backend.
- Progressive lessons on API fundamentals and common weaknesses
- Intentionally vulnerable API scenarios for local, controlled practice

`Svelte` `Python` `FastAPI` `OWASP API Top 10`

### [Vulnerable Hospital](https://github.com/amrikhore86/vuln-hospital)
An intentionally vulnerable web application, in the spirit of OWASP Juice Shop, for exploring how insecure implementation patterns lead to real vulnerabilities.

`Python` `Web Security` `Training Lab`

### [PortSwigger Lab Scripts](https://github.com/amrikhore86/portswigger-solution-scripts)
Python scripts from my PortSwigger Web Security Academy practice, organized by vulnerability category.

`Python` `Web Pentesting`

### [JCTF](https://github.com/amrikhore86/jctf)
A collection of CTF challenges for security practice and experimentation.

`CTF` `Problem Solving`
